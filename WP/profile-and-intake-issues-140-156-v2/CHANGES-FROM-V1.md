# Changes from v1

v2 keeps v1's diagnosis, identity model, safety rules and design detail. It changes how the work is sliced and adds explicit decisions. The owner-authorized revision on 3 October 2026 retains Opus's four increments and incorporates the independent source review. All four increments are now authorized without waiting for contributor replies; this is a delivery plan, not a claim of implementation. v1 remains unchanged in `WP/profile-and-intake-issues-140-156-v1` for comparison.
