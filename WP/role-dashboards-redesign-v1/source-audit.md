## Outstanding evidence to obtain during implementation

- Resolve real grants from `User.countries`, `User.projects`, lab assignment and role; validate scoped count/list behavior for all ten roles using synthetic users. The registry is not evidence of endpoint permission parity.
- Determine active order-line/work-attempt identity and legacy adapters using current v3 code. No automatic historical state rewrite, invented receipt date or QC waiver.
- Verify supported workbench deep links and batch/run selection at the destination. Today it accepts analysis/method (as analysis code) and sampleId/sample, not a true method-revision/run filter.
- Inspect result report download, spectral read, maps and audit endpoints used by dashboard links. Findings in linked access rules are release blockers for those role views, even if the bug predates the redesign.
- Confirm actual lab timezones and whether receipt reversals retain custody history. Do not show server-local “today” as a lab-local fact.
- Recheck reception commit successors and attach test evidence to D13/D14. The earlier counts/location correction does not prove these new cases.
