# Manual Screenshot Shot List & Demo Lab Seed Specification

This shot list covers all 41 screenshot placeholders across `docs/book/src/` so every image in the user manual can be captured from a single reproducible *Demo Soil Lab* seed (`DEMO`), using the current plain-language English screen labels.

## Capture Conventions

- *Language & theme:* **English** (`en`), **Light** mode (`1440 × 900` desktop viewport, `100%` zoom) unless a shot specifically highlights theme options.
- *Privacy & realism:* Use fictional staff names, realistic agronomic soil values, and the demo facility *Demo Soil Lab* (`DEMO`)—never real client names, phone numbers, or GPS points of private farms.
- *Target paths:* 36 pages already name their `docs/book/src/img/screenshots/<file>.png` target inline; the 5 setup/admin pages whose placeholders have description text only are marked *(proposed filename)* below so the image filename and markdown link can be wired together cleanly.

## 6. Demo Soil Lab Seed Needs Summary

A single deterministic seed script for *Demo Soil Lab* (`DEMO`) covers all 41 screenshots above without resetting database state between captures. See [Set Up the Practice Lab](practice-lab-setup.md) for the command and safety rules to populate a local practice database.

- *Laboratory:* `Demo Soil Lab` (code `DEMO`, timezone `UTC`, branding logo set, **ISO 17025 strict** starting rule set active).

  - **Require a second reviewer** = **Yes** and **Require a second person for amendments** = **Yes**
  - **Sample retention after report** = `365` days

- *Active soil parameters (with GLOSOLAN defaults, plausible min/max, LOQ, and 5-tier agronomic thresholds):*
