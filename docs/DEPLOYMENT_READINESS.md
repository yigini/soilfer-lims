# Installation and deployment readiness

The current installation procedure is consolidated in [INSTALL.md](INSTALL.md).
It covers sizing, TLS setup, proxy trust, browser origins, first sign-in,
certificate renewal and off-host backups.

For an existing instance, follow [UPGRADING.md](UPGRADING.md); review the exact
release, require passing checks, verify backups and available disk space, and
confirm health after the approved update. Historical readiness notes are retained
in repository history and are not a statement of the current installation.

The [operator book](book/src/welcome.md) covers laboratory administration and
ongoing maintenance.
