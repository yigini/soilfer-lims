# #208: issued labels and print evidence

Sample, container and aliquot labels share one print dialog and server authority. QR and Code128 contain the exact persisted issued code. Samples resolve through the approved `sampleCodeService.issuedCode` authority; containers use their immutable `SampleContainer.code`. Current format policies never reinterpret or renumber an issued identity. Fresh codes retain the approved ISO 7064 MOD 37,36 check character. Historical/no-CHK policies remain printable byte-for-byte; they are not silently assigned a new check character. The hybrid checksum's adjacent-transposition limitation is documented in `sample-code-numbering.md`.

`PRINT_LABELS` belongs to reception, technicians, laboratory managers, national master users and super administrators. Every preview and print re-reads the authoritative sample and uses the shared scope guard. Rejected/disposed samples, inactive containers, missing permanent codes and unsupported Code128 characters return stable 4xx codes. Preview creates no event. Pre-arrival samples without an issued laboratory code cannot print a permanent label.

`POST /api/samples/labels/preview` accepts `items: [{entity: "SAMPLE" | "CONTAINER", entityId, count}]`. `POST /api/samples/labels/print` additionally requires `format: "STANDARD" | "COMPACT"` and a nonblank `reason` when any selected identity has a previous print event. Aliquots are container identities. The server derives codes, parents, actor, timestamp and next print ordinal; the client cannot supply them. A batch is atomic, accepts 1–20 copies per identity and at most 200 labels, and refuses duplicate identities. Concurrent or stale previews cannot evade reprint reason enforcement.

Each successful request appends one `LabelPrintEvent` per identity with its immutable issued code, sample/container references, count, ordinal, format, reason, `by` and `at`. Database triggers enforce valid references, copy counts, sequential ordinals and reprint reasons, and forbid event updates/deletes. No historical print events are inferred. The event records a **browser print request**, not confirmation that paper physically left the printer. Cancellation, a browser failure or loss of the response leaves the event recorded; a subsequent request is a reprint. The UI makes printable DOM available only after the event transaction commits and clears it after printing.

Standard labels are 101 × 54 mm; compact labels are 50 × 25 mm. Code128 is a local vector generated by JsBarcode with automatic mode switching and ten-module quiet zones. The dialog refuses formats that would reduce modules below 0.19 mm (95/46 mm available width). Long codes require standard labels; identities too long for standard labels need laboratory review and are not truncated. Printer resolution, media and physical scanner acceptance remain part of post-deployment laboratory acceptance.

The additive migration is `20261016000100_label_print_events/migration.sql`. The established installer pattern is used:

```text
node scripts/install_label_print_events.js --db <existing SQLite file> --dry-run
node scripts/install_label_print_events.js --db <existing SQLite file> --apply
```

The default is read-only dry-run. Apply verifies the #206 prerequisite, exact release objects, integrity, foreign keys and preservation of all existing rows, then installs one table, three indexes, three guards and a receipt. Empty fresh Prisma storage may gain its guards; populated unmarked, partial, changed or invalid-receipt storage is refused. Repeat apply is a zero-write no-op. Entrypoint and application startup require the complete installation. These source changes grant no release or deployment authority.

Contracts exercise fresh checksums, historical byte preservation, sample/bulk/aliquot batches, reprint reasons, concurrency, roles/scope, localized 4xx responses, immutable guards, dry-run/apply/no-op/refusals and the pinned SQL scanner. Real React tests exercise both barcode identities and the commit-before-print boundary. All new text is present in English, Spanish, Latin American Spanish, French and Portuguese.
