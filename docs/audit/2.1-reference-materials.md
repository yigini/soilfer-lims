# Reference materials — audit 2.1 (#184)

WIP on merged #182/main. The absence of catalogue models and the unlinked control write path were confirmed before implementation. Scope pins [6009757542](https://github.com/yigini/soilfer-lims/issues/184#issuecomment-6009757542) and [6009891898](https://github.com/yigini/soilfer-lims/issues/184#issuecomment-6009891898) govern the work.

The foundation adds a per-lab material/certificate/lot catalogue and immutable assigned values, with nullable certificate coverage factor. Correction creates a replacement and supersedes the old value atomically; it never changes the recorded value fields. Linked QC controls retain their value and placement snapshot. Current generic and method-specific values use separate partial unique indexes.

Eligibility uses stored expiry instants and linked inventory eligibility. The effective expiry is the earlier material/lot instant. Reading expiry never writes a status. Only the expiry warning uses a per-lab policy value (`referenceMaterials.expiryWarningDays`, shipped default 30). Calendar cutoffs are deferred pending a timezone policy. Control charts and real run-member positions remain outside #184.

Remaining implementation: exact additive installer/startup integrity, both real QC placement paths, scoped catalogue routes, Admin Quality UI and control selectors, five-locale strings, behavioral/rollback/preservation tests, full server/build/lint checks and independent Claude audit. This branch has no production changes and is not audit-ready.
