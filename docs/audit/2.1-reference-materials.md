# Reference materials — audit 2.1 (#184)

This change adds a per-lab reference material catalogue under Admin → Quality. The absence of catalogue models and the unlinked control write path were confirmed before implementation. Scope pins [6009757542](https://github.com/yigini/soilfer-lims/issues/184#issuecomment-6009757542) and [6009891898](https://github.com/yigini/soilfer-lims/issues/184#issuecomment-6009891898) govern the work. The approved #183 implementation is integrated from main; its installer, startup gates and frozen sources are retained.

Material, certificate and lot facts are immutable. Manual status changes require an audited reason. Per-analyte assigned values have separate current-row partial unique indexes for generic and method-specific values. A reasoned correction supersedes the old row once, inserts a replacement and writes the audit in one transaction; failed insertion or audit rolls the whole correction back. Corrected history, typed QC references and historical QC audit references cannot be deleted. Certificate coverage factor is nullable and must be supplied with expanded uncertainty; no value is invented.

Both existing QC update and evaluate transactions validate optional reference links. Use is explicit (CRM or LRM), while the server derives the method from the batch WorkItems. Only one distinct non-null method with no null members permits exact-method lookup before the generic fallback; other batches use a generic value. The expected value comes from the assigned value converted through controlled units. An unchanged saved link retains its original value and placement snapshot after expiry, quarantine or correction. Legacy unlinked controls remain usable; existing batches and QC rows are never back-filled or re-evaluated.

Eligibility requires ACTIVE material status, an unexpired stored UTC instant and, when linked, an AVAILABLE inventory lot in the same lab with an unexpired instant. Effective expiry is the earlier material or lot instant. Reading expiry never writes a status. Only the warning reads a lab policy: `referenceMaterials.expiryWarningDays`, shipped preset default 30 with lab overrides. The interface lists lots, derived eligibility and days to expiry, and current and superseded values. Catalogue forms, QC selectors and errors have keys in all five client and server locales.

The additive migration adds two tables, two nullable BatchQcResult foreign-key columns, four indexes and seven guards. The exact release SQL and fresh-Prisma table oracle are SHA-bound. The installer and read-only startup gate refuse partial or mismatched schema, invalid typed links and invalid supersession targets. Docker packaging and legacy/fresh test fixtures use the actual installer. Frozen #179, #182 and #183 sources and the original real Docker boundary remain unchanged.
