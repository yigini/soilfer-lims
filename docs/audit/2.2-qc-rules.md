# Audit 2.2: immutable QC rules

Issue #185 scope pins: 6015099533, 6015163452, 6016488612, 6016879106. No rule rows are seeded and no old QC or analytical history is backfilled.

## Installation

Back up the stopped database and assets using the release procedure. Run the installer first on an owned database copy; compare every pre-existing table, field, schema object and row before/after. Never run Prisma db push against an existing live database.

```sh
node server/scripts/install_qc_rules.js --db /owned/copy/dev.db --dry-run
node server/scripts/install_qc_rules.js --db /owned/copy/dev.db --apply
node server/scripts/install_qc_rules.js --db /owned/copy/dev.db --apply
```

The dry run is read-only. Applying adds only QcRule, two indexes, five guards and one migration receipt. Counts report rules and zero backfill. A repeated apply is NO_OP with zero changes. Fresh Prisma installations receive the same guards; partial, unmarked or altered definitions are refused. Direct startup performs a read-only gate before loading the app, database writer or schedulers. Docker installs the digest-bound source outside the database volume.

## Rules and evidence

Lab policy permission and scope gates control GET/POST `/api/qc/rules`. Editors provide labId, analysisCode, optional methodologyId, expectedVersion, reason and criteria. Each edit inserts max(version)+1; reset inserts all-null criteria. effectiveFrom defaults to the server time; future ISO timestamps are accepted and backdating is refused. Approved actor and one before/after audit row are written in the same transaction. Database guards prohibit changes/deletion of rule rows.

Resolution selects an effective exact recorded-method rule before a generic rule. Each nonnull field wins over an analysis/method policy override, then shipped global-analysis criteria, then lab/profile/preset policy. Mixed recorded methods use only generic rules. Each evaluation freezes the selected rule and every field's value/source in its JSON summary and typed QC details. Earlier evidence is preserved by the existing QC evidence snapshot transaction; it is never backfilled.

Policy edits validate inherited bounds against every current or scheduled QC rule scope in the same transaction, including method-policy interactions with generic rules. A conflict returns 409 POLICY_QC_RULE_CONFLICT and rolls back the complete edit, leaving existing batch reads and evidence available. Superseded historical rule versions do not block compatible edits. A method-level reset remains selected ahead of a generic rule and inherits policy values through its blank fields.

Blanks use absolute magnitudes, including LOQ modes. Missing/invalid LOQ produces INVALID/NO_LOQ rather than substituting another criterion. Duplicates preserve #177 invalid/censored handling and support configured ABS_DIFF. CRM absolute windows apply only with a configured value; otherwise recovery is used with ABS_WINDOW_UNSET. LRM control charts use the provisional fixed window with PROVISIONAL_NO_CHART.

Blank, duplicate, CONTROL profile and LRM counts are recorded separately. A disabled type overrides profile minima. Enabled types retain profile minimum counts. CRM never satisfies LRM; unlinked legacy controls do. REQUIRED_WARN stores count warnings; ADVISORY/OFF offer entries without requiring them. Optional entries are still evaluated and their failures remain visible.

The explicit evaluation API preserves #163's input guard: an entirely omitted required type in blocking mode, or an actually submitted incomplete entry in any mode, returns QC_VALUES_MISSING before any write. At least one complete entry but insufficient counts produces the configured count verdict. A warning/advisory/off mode never input-requires an omitted type.

Per pin 6016879106, general PUT retains its existing 200/QC_FAIL behavior for invalid submitted evidence, preserving the invalid values and marking them FAIL. Its empty clear/reopen path retains #164 permissions and locks. This known difference from POST /evaluate is deferred to #186's append-only measurement/evaluation replacement.
